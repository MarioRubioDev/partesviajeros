# **App Name**: XML Traveler's Pie

## Core Features:

- Schema Upload: Upload XML schema (.xsd) file.
- Data Input: Enter data for required fields according to the loaded schema. Populate combo-boxes and other UI elements using 'condiciones.json' and 'datos.json'.
- XML Generation: Generate XML file based on schema and user input.
- XML Download: Download the generated XML file.
- AI Suggestion: Provide AI-powered suggestions for completing missing fields based on similar data patterns and schema constraints. The AI acts as a tool, providing suggestions, not automatically filling data.

## Style Guidelines:

- Primary color: Soft blue (#79A7D3), evoking a sense of reliability and trust.
- Background color: Light blue (#EBF2F8), a desaturated variant of the primary to maintain visual harmony.
- Accent color: Pale yellow (#D4AC0D), used to highlight important actions and guide the user's focus.
- Font pairing: 'Literata' (serif) for titles and headings to provide a classic and readable structure, with 'Inter' (sans-serif) for the body to keep the application sleek and approachable.
- A clean and structured layout will be adopted to guide the user through the schema and data entry processes.
- Simple and intuitive icons should represent actions (upload, download, generate).
